Greatest Common Divisor

The Greatest Common Divisor is defined (gcd) as if a,b\in\mathbb{Z}-\{0\}, satisfy : a\mid d,b\mid d\land e\mid a,e\mid b,e\mid d we say \gcd(a,b)=d, speaialy \gcd(a,b)=1 if and only if a,b is prime

Theorem 1. \forall d\mid a,d\mid b, \forall x,y, d\mid ax+by

Proof. According to the define : \exists m,n\in\mathbb{Z} equal : a=md,b=nd ax+by=(mx+ny)d d\mid ax+by ◻

Stein’s algorithm

if 2\mid a,2\mid b, \gcd(a,b)=2\gcd(\frac{a}{2},\frac{b}{2}) else \gcd(a,b)=\gcd(\frac{a}{2},b)

Euler’s totient function

For n\in\mathbb{Z^{+}}, the Euler’s totient function \phi(n) is defined as a postive number a\le n and relatively prime. \phi(n)=n\prod\limits_{i=1}^{k}(1-\frac{1}{p_i}), p is prime. According to theorem 0.1., an obvious conclusions is \phi(n) is even when n>2. that’s because the \gcd is always come out by a pair. Going by a step further, the sum of numbers less than or equal to n and coprime to n is \frac{n}{2}\phi(n),n>1

Theorem 3. Given N, the number of n such that \phi(n) is finite.

Proof. n=\prod\limits_{i=1}^{k}p_i^{\alpha_i} \phi(n)=\prod\limits_{i=1}^{k}p_i^{\alpha_i-1}(p_i-1)=N p_i-1\mid N,p_i\le N+1 Obviously,the number of p_i is finite. so \alpha_i is finite. ◻

If we perform a discrete Fourier transform on the Euler’s totient function, we can calculate \phi(n) online in nlogn time. According to DFT we have : \mathbf{F}[x][m]=\sum\limits_{k=1}^{n}x_i\exp(-2\pi\frac{mk}{n})where m=1,x_i=\gcd(k,n) \phi(n)=\sum\limits_{k=1}{n}\gcd(k,n)\exp(-2\pi\frac{mk}{n}) \phi(n)=\sum\limits_{k=1}{n}\gcd(k,n)\exp(\frac{2\pi k}{n})
