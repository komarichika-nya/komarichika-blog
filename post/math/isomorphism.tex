\begin{theorem}
    if $\varphi:G\to H$ is isomorphism, $\forall x\in G,|\varphi(x)|\mid|x|$.
\end{theorem}
\begin{proof}
    $\varphi$ is isomorphism, $\varphi(x^n)=\varphi(x)^n$, this is tirval.
    if $n$ is the order of $x$, so $\varphi(e)=\varphi(x)^n$, let m is the order of the $\varphi(x)$
    $\varphi(x)^m=e=\varphi(e)$, so $n=mq+r,\forall r\in[0,m)$, $\varphi(x)^r=\varphi(x)^n(\varphi(x)^m)^{-q}$,
    so, $n=mq$.
\end{proof}
