Q: construct a set X equal \mathcal{O}(G\curvearrowright X)=|G| and the group action is faithful.
A: I will present a method based on coset decomposition. For H\le G, the left coset space is G/H=\{xH\mid x\in G\}. Consider act on G, so (\forall g,x\in G)g\cdot(xH)=(gx)H. Obviously, G/H is an obrit and |G/H|=[G:H]. The kernel of this action is \ker(G\curvearrowright G/H)=\bigcap\limits_{g\in G}gHg^{-1}=:\operatorname{Core}_G(H). The essence of this problem lies in the gluing of coset space. Specificly, let \{H_i\}_{i\in I}, X=\bigsqcup\limits_{i\in I}G/H_i. Every G/H_i is an obrit. we only need \ker(G\curvearrowright G/H_i)=\{1\}\land|I|=|G|. A key observation is (\exists H_i)\operatorname{Core}(H_i)=\{1\} not \forall H_i.
A important truth is \mathcal{O}=|G|=|X|\iff every points are fixed points \iff trivial action. In the other word, if you want the action is faithful, then |X|>|G|. What is this lower bound? if we split X with orbit, then X\cong\bigsqcup\limits_{i=1}^{|G|}G/H_i, in order to ensure faithful \bigcap\limits_{i=1}^{|G|}\operatorname{Core}(H_i)=\{1\}. so |X|=\sum[G:H_i]\ge1. Faithfulness only requires ensuring that one orbit is non-trivial. |X|\ge(|G|-1)\times1+2=|G|+1. so |G|=2. Interestingly, Only \mathbb{Z}/2\mathbb{Z} can equal.
