\subsection{pseudo-random generator}
A pseudo-random number generator can be abstracted as a finite state machine $\mathcal{G}=(S,O,s_0,f,g)$.
$\exists f:S\to O$, $g:O\to O$ $S=\{0,1\}^b$, $|S|=2^b$, $O=\{0,1\}^r$. The state transition is $g(s_t)=s_{t+1}$, $f(s_t)=y_t$. if the $s_0$ is fixed, anything can be compute. Such as preiod $T\le|S|=2^{b-r}$. 
At this point, $f$ is surjective and $\sum\limits_{y\in O}=|S|=2^b$.
The quality of random number generator is constrained by is internal state. Suppose we have a generator which 
have $b$ bits internal states and output $r$ bits number everytime.$(b\ge r)$ So the cycle is $2^b$ and the types of numbers are $2^r$.
Uniformly requires us the number which is $r$ bit must appear $2^{b-r}$. An extreme example is $r=b$.
That means each number will not repeat before the cycle is completely traversed. However, this is not the case in real randomness.
In real randomness, each number are independently repeatable. We can use birthday problem to model this.
Given $m=2^b$ possibilities, draw $n=2^r$ independent and uniform samples, $X$ is the repeat at least once. The birthday problem given $P(X)=1-\frac{m(m-1)(m-2)\cdots(m-n+1)}{m^n}$
Actually, we can use Poisson distribution approximation.
$\lambda\approx\binom{n}{2}\frac{1}{m}=\frac{n(n-1)}{2m}$
$P(X)\approx\exp(-\frac{n(n-1)}{2m})$
Ideally, the possibility of repeating at least once is hightest around time $\sqrt{m}$.\\
Q: The birthday problem tell us that repeatition of output values always occurs too early.
So does the finite-state PRNG fail statistically even earlier?\\
A: No. The success or failure of a finite-state PRNG depends solesly on its internal state space; the birthday problrm's appearance is inevitable, and it provides with a benchmark for evaluation.\\
Q: Consider a uniform mapping with an internal value state sapce of $2^b$ and an output value state of $2^r$, where $b>r$.
According to the pigeonhole principle, each number appears approximationly $2^{b-r}$ times within one period. 
What is the expected number of times the output value appears more than $2^{b-r}$ times?
A: Let internal state $N=\{0,1\}^b$ and output state $V=\{0,1\}^b$. To solve this problem, we will use multionmial distribution. 
$\forall v_i\in V$, the corresponding probability $p_i$ where $i\le 2^r$, let $X_i$ is $v_i$ occurrences. so $\sum\limits_{i=1}^{2^r}X_i=2^b$. $X_i\sim\mathcal{M}(2^b,\frac{1}{2^r})$. For each $f:N\to V$ is uniformation. So it can be approxed $X_i\sim\mathcal{B}(2^b,\frac{1}{2^r})$. Let us consider the excepted number of times a fixed appears more than once. $\mathbb{E}[\mathbf{1}_{X_i>1}]=P(X_i>1)=1-P(X_i=1)-P(X_i=0)$, $P(X_i>1)=1-(1-p_i)^n-np_i(1-p_i)^{n-1}$,$P(X_i>1)=1-(1-2^{-r})^{2^b-1}(1+\frac{2^b-1}{2^r})$. Let $Y=\sum\limits_{i=1}^{2^r}\mathbf{1}_{X_i>1}$, $\mathbb{E}[Y]=\sum\limits_{i=1}^{2^r}\mathbb{E}[\mathbf{1}_{X_i>1}]=\sum\limits_{i=1}^{2^r}P(X_i>1)=2^rP(X_i>1)$. 
$\mathbb{E}[Y]=2^r\left(1-(1-2^{-r})^{2^b}-2^b\cdot2^{-r}(1-2^{-r})^{2^b-1}\right)$.

\subsection{xorshift}
A 32-bit integer can be regarded as $x=(x_0,x_1,\dots,x_31)\in\mathbb{F}_2^{32}$, $\mathbb{F}_2=\{0,1\}$.
or it could be viewed as $\langle\mathbb{F}_2,\oplus\rangle$. A shift can be ragarded as a linear mapping.
$x\mapsto(I+L^n)x$. so the state transition of xorshift can be written $T=(I+L^5)(I+R^{17})(I+L^{13})$. Obviously, 
$T$ is invertible. The question is, how long is its period? We consider its characteristic ploynomal. $f(t)=\det(tI-T)\in\mathbb{F}_2[t]$. also, $f(t)=\det(tI+T)$. so $f(t)=t^{32}+t^{22}+t^2+t+1\in\mathbb{F}_2[t]$. This is a source 
polynomial with a maximum period of $2^{32}-1$. Here, we can carry out a quick check. All you need to do is check 
$2^{2^{32}-1}=1\land\forall p\in\{3,5,17,257,65537\},2^{(2^{32}-1}/p)\ne1$.

def pmul(a,b,mod):
    ans=0
    while b:
        if b&1:ans^=a
        b>>=1
        a<<=1
    while ans.bit_length()>=mod.bit_length():
        sft=ans.bit_length()-mod.bit_length()
        ans^=mod<<sft
    return ans
def ppow(a,b,mod):
    r=1
    while b:
        if b&1:r=pmul(r,a,mod)
        a=pmul(a,a,mod)
        b>>=1
    return r
