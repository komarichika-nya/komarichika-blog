Rasterization maps objects in a 3D scene onto a 2D screen, while ray tracing maps 2D pixels onto a 3D screen. Let's first look at rasterization. How does it map objects in a 3D scene onto a 2D screen? An important transformation is called the MVP (Model, View, Projection) transformation. Let's derive the MVP matrix in detail: First, we can define the matrix product like this:

A camera is essential in any scene; all our observations begin with it. Here, we establish a standard right-handed coordinate system with the default viewpoint towards the -z axis and the y-axis at the top. We use R (right), U (up), and F (front) to represent the three directions of the camera. Let's define the camera's coordinate system, including the rotation section:

$$ R=\begin{pmatrix}R_x&R_y&R_z&0\\U_x&U_y&U_z&0\\-F_x&-F_y&-F_z&0\\0&0&0&1\end{pmatrix} $$ Translation part: If the camera is at world coordinates $P$, then: $$ T=\begin{pmatrix}1&0&0&-P_x\\0&1&0&-P_y\\0&0&1&-P_z\\0&0&0&1\end{pmatrix} $$ The coordinate system of all cameras can be defined as: $$ V=R*T=\begin{pmatrix}R_x&R_y&R_z&-dot(R,P)\\U_x&U_y&U_z&-dot(U,P)\\-F_x&-F_y&-F_z&dot(F,P)\\0&0&0&1\end{pmatrix} $$ We can then define a camera class like this:

Using the $V$ matrix, we successfully brought the world to the camera's view. However, since the screen is 2D and the world is 3D, we need a transformation to map the 3D to 2D. Therefore, we can define a matrix like this: $$ \begin{pmatrix}\frac{1}{a\tan\frac{\alpha}{2}}&0&0&0\\0&\frac{1}{\tan\frac{\alpha}{2}}&0&0\\0&0&\frac{f+n}{f-n}&\frac{-2.0*f*n}{f-n}\\0&0&-1.0&0\end{pmatrix} $$ Here, $\alpha$ refers to the field of view (fov). We use the tangent value to scale the field of view, but after scaling $x$ and $y$, the depth $z$ remains distorted. We hope to find two constants $a$ and $b$ to correct the depth $z$. Let $n$ be the approach point and $f$ be the apogee. $$ z'=\frac{a*z+b}{-z} $$ $$ -1=\frac{a*n+b}{-n}\\[10pt]1=\frac{a*f+b}{-f}\\[10pt]A=\frac{f+n}{f-n},B=\frac{-2.0*f*n}{f-n} $$ Now that we've finally brought the world to the camera, let's begin rendering!!!

Triangle Traversal For a point inside the triangle, satisfying: $P(u,v)=(1-u-v)p_0+up_1+vp_2$, simplifying: $$ u(p_1-p_0)+v(p_2-p_0)+p_0-P(u,v)=0\\[10pt]dot([u,v,1],[p_1-p_0,p_2-p_0,p_0-P(u,v)]) $$ Calculate the dot product, then divide by zero to prevent it from spreading out. Ray Tracing Ray tracing: The general idea is to emit a ray from the camera; if it hits a triangle, it's rendered. For each pixel, how do we know where the ray went? Simply multiply by $(P*V)^{-1}$. $$ (P*V)^{-1}=V^{-1}*P^{-1}\\[10pt]V^{-1}=\begin{pmatrix}R_x&R_y&R_z&0\\U_ x&U_y&U_z&0\\-F_x&-F_y&-F_z&0\\P_x&P_y&P_z&1.0\end{pmatrix}\\[10pt]P^{-1 }=\begin{pmatrix}a\tan\frac{\alpha}{2}&0&0&0\\0&\tan\frac{\alpha}{2}&0&0\\0&0&0&-1.0\\0&0&-\frac{f-n}{2.0*f*n}&\frac{f+n}{2.0*f*n}\end{pmatrix} $$ $$ (P*V)^{-1}=V^{-1}*P^{-1}\\[10pt]V^{-1}=\begin{pmatrix}R_x&R_y&R_z&0\\U_x&U_y&U_z&0\\-F_x&-F_y&-F_z&0\\P_x&P_y&P_z&1.0\end{pmatrix}\\[10pt]P^{-1}=\begin{pmatrix}a\tan\frac{\alpha}{2}&0&0&0\\0&\tan\frac{\alpha}{2}&0&0\\0&0&0&-1.0\\0&0&-\frac{f-n}{2.0*f*n}&\frac{f+n}{2.0*f*n}\end{pmatrix} $$ Let's define a ray $P(t) = o + t * d$. The problem is, for each ray, we need to traverse every triangle, which would be incredibly complex. We need to optimize this; there are many methods, such as k-d trees and BVH (Bounded Value Hierarchy). Here's a BVH implementation: The basic idea is to divide the object into a bounding box aligned to the aabb axis. When reaching a leaf node, we insert the object's triangle into it. During traversal, we only need to check if the bounding box contains anything; if not, we return directly. Specifically, we define the aabb bounding box and maintain the coordinates of the bottom left and top right. We define the time for the ray to travel from $o$ to $d$ as $\frac{P(t) - o}{d}$. The check calculates the time difference between the ray entering and leaving the bounding box. The latest entry time is greater than the earliest exit time. $$ [tmn,tmx]=[tx_1,tx_2]\cap[ty_1,ty_2]\cap[tz_1,tz_2] $$ To build, call the following function.

When the light ray hits the triangle, the following condition is satisfied: $$ o+t*d=(1-u-v)A+uB+vC\\[10pt]o-A=u(B-A)+v(C-A)-t*d $$ Let $T=o-p_0,S_1=B-A,S_2=C-A$, then it can be written as: $$ T=\begin{bmatrix}S_1&S_2&-d\end{bmatrix}\begin{bmatrix}u\\v\\t\end{bmatrix} $$ According to Cramer's rule, for $Ax=B$, we have $\frac{\det(A_i)}{\det(A)}$, where $A_i$ is the matrix obtained by swapping $B$ to this column. Therefore: $$ let:Det(\begin{bmatrix}S_1&S_2,-d\end{bmatrix})\\[10pt] $$ $$ u=\frac{\det(\begin{bmatrix}T&S_2&-d\end{bmatrix})}{Det}=\frac{dot(cross(T,S_1),-d)}{Det}\\[10pt] v=\frac{\det(\begin{bmatrix}S_1&T&-d\end{bmatrix})}{Det}=\frac{dot(cross(S_1,T),-d)}{Det}\\[10pt] t=\frac{\det(\begin{bmatrix}S_1&S_2&T\end{bmatrix})}{Det}=\frac{dot(cross(S_1,S_2),T)}{Det}\\[10pt] $$ If and only if the following condition is met: $$ u<0\lor u>1\lor v<0\lor u+v>1\lor t< eps $$ is not valid. Note the back face culling here; it's best not to perform back face culling before knowing the direction of the triangle's wrapping.
