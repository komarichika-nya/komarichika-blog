The Holomorphic function is defined as:
\[\{U\subseteq\mathbb{C},f:U\to\mathbb{C}:\forall z_0\in U,\exists\lim_{h\to0\land h\in\mathbb{C}}\frac{f(z_0+h)-f(z_0)}{h}\}\]
The Univalent function is defined as:
\[\{U\subseteq\mathbb{C},f:U\to\mathbb{C}:f is Holomorphic\land\forall z_1,z_2\in U(z_1\ne z_2\implies f(z_1)\ne f(z_2))\}\]
Obviously, Holomorphic is equal to analytic.\\

$f:\mathbb{C}\to\mathbb{C}$, if $\{\exists z_0:f(z_0)=z_0\}$ then we call $z_0$ is a fixed point. The multiplier $\lambda$ is defined as $\lambda=f'(z_0)$,
$|\lambda|$ decided the fixed point's locally dynamic.

\[\exists k>=2,f(z)=a_kz^{k}+a_{k+1}z^{k+1}+\cdots=a_kz^k+\mathcal{O}(a_{k+1}z^{k+1}),a_k\ne0\]
